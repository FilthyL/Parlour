# Sound effects

Casino Audio by Kenney (www.kenney.nl), licensed CC0 1.0 — see
`LICENSE-kenney-casino-audio.txt` and `LICENSE-kenney-boardgame-pack.txt`.

The original OGG files were recovered from a public game repository's Godot
import cache (OggPacketSequence resources re-wrapped into Ogg pages), then
encoded to mono 80 kbps MP3 for universal browser playback.
